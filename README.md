# StockIntel Pro 📈
## מערכת חכמה לניתוח מניות, חיזוי ביצועי השקעות ואופטימיזציה של תיקים

מערכת Web אנליטית מתקדמת מבוססת Python (FastAPI + HTML5/CSS3/Plotly.js) לניתוח מניות, הערכת שווי הוגן (DCF), סימולציות מונטה קרלו והסתברויות ביצועים – **בתקציב של 0 ש"ח**.

---

## 🌟 עקרונות הליבה של המערכת

1. **תקציב אפס (Zero Budget):** שימוש בלעדי בספריות קוד פתוח (Open Source), מקורות נתונים חינמיים ורשמיים (Yahoo Finance + SEC EDGAR), והרצה מקומית ללא עלויות ענן.
2. **אמינות ומדע פיננסי ללא שרירותיות:**
   * אין "קופסאות שחורות" או ציוני קסם.
   * כל ציון (0–100) מבוסס על מודלים פיננסיים ואקדמיים קלאסיים (Piotroski F-Score, Altman Z-Score, DCF, Multiples, CAPM).
3. **חיזוי הסתברותי מדעי (ללא אשליית דיוק):**
   * שימוש ב-5,000 סימולציות מונטה קרלו בשילוב דגימת Block Bootstrapping המשמרת "זנבות שמנים" (משברים כלכליים שאינם גאוסיאניים).
   * הצגת הסתברויות להכאת מדד S&P 500 בטווחי 3 חודשים, 6 חודשים, שנה ו-3 שנים, יחד עם תרחישי P10 (דובי), P50 (בסיס) ו-P90 (שורי).
4. **עברית מלאה ו-RTL מוקפד:** ממשק מודרני מבוסס גופן Google Assistant, בידוד תווי BiDi לסימולים לועזיים, וגרפים אינטראקטיביים.
5. **ארכיטקטורה מודולרית (Clean Architecture):** שכבת ספקי מידע (Adapter Pattern) המאפשרת החלפה עתידית של Yahoo Finance בספקים בתשלום (Bloomberg / FactSet) ללא שינוי בקוד הלוגיקה.

## 🚀 הוראות התקנה והפעלה מקומית

### 1. דרישות קדם
* Python 3.10 ומעלה (נבדק ומותאם ל-Python 3.13)
* דפדפן אינטרנט מודרני (Chrome, Edge, Firefox)

### 2. התקנת תלויות
בטרמינל / PowerShell:
```bash
cd stock_intel
pip install -r requirements.txt
```

### 3. הפעלת המערכת
```bash
python run.py
```

לאחר ההפעלה, פתח את הדפדפן בכתובת:
👉 **http://127.0.0.1:8000**

תיעוד ה-API המלא (Swagger UI) זמין בכתובת:
👉 **http://127.0.0.1:8000/docs**

### 4. הרצת בדיקות יחידה (Unit Tests)
```bash
python -m unittest discover -s tests -p "test_*.py"
```

## 🧮 הסבר על המודלים והאלגוריתמים

### 1. מנוע הערכת שווי (DCF - Discounted Cash Flow)
* **תזרים מהוון:** המערכת חוזה תזרים מזומנים חופשי (FCF) ל-5 שנים קדימה בהתבסס על ביצועי החברה וצמיחתה ההיסטורית.
* **עלות הון משוקללת (WACC):** נגזרת ממודל CAPM על פי ריבית חסרת סיכון (אג"ח ארה"ב ל-10 שנים), בטא היסטורית ופרמיית סיכון שוק.
* **ערך טרמינלי (Gordon Growth):** מחושב לפי צמיחה שמרנית לטווח ארוך (2.5%).
* **סימולטור רגישות אינטראקטיבי:** המשתמש יכול לשנות בזמן אמת את שיעור ההיוון (WACC) ואת קצב הצמיחה באמצעות סליידרים בדפדפן, ולראות מיד כיצד השווי ההוגן ושולי הביטחון משתנים.

### 2. איכות פיננסית ויציבות
* **Piotroski F-Score (0 עד 9):** בדיקת 9 קריטריונים של רווחיות, מינוף ויעילות תפעולית. חברות עם ציון 8-9 מוגדרות כבעלות עוצמה פיננסית יוצאת דופן.
* **Altman Z-Score:** אלגוריתם מוכח סטטיסטית לחיזוי חדלות פירעון ומצוקה פיננסית לשנתיים הקרובות.

### 3. מנוע חיזוי הסתברותי
* **סימולציית Monte Carlo (5,000 תרחישים):** הרצת מודל Geometric Brownian Motion (GBM) משולב עם Block Bootstrapping (דגימת תשואות עבר אמיתיות), הממפה את כל מרחב התוצאות האפשריות.
* **חישוב הסתברויות:** מציג במפורש את ההסתברות לתשואה חיובית ואת ההסתברות שהמניה תכה את מדד S&P 500 בטווחי 3 חודשים, 6 חודשים, שנה ו-3 שנים.
* **תרחישי קצה:** תרחיש פסימי (P10), תרחיש בסיס (P50) ותרחיש אופטימי (P90) עם מחיר ותשואה צפויים.
